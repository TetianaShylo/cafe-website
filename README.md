# ☕ Artisan Café & Bakery Website

A responsive, interactive single-page web application for a modern artisan café and bakery in Kyiv. Built with modern JavaScript, Vue 3, and CSS Glassmorphism design principles.

---

## 🌟 Key Features

* Interactive Menu & Category Filtering: Dynamic category switching powered by Vue 3 reactivity without page reloads.
* Interactive Shopping Cart: Real-time item management with dynamic subtotal calculations and drawer sidebar.
* Online Table Reservation System: Interactive booking form with reactive inputs and confirmation feedback.
* Modern Auth Modals: Clean popups for *Sign In* and *Sign Up* workflows.
* Glassmorphism UI: Elegant coffee-themed dark palette, responsive typography, and smooth CSS transitions.

---

## 🛠️ Built With

* HTML5 & Modern CSS3 — Flexbox, CSS Grid, Glassmorphism backdrop filters, custom CSS variables.
* Vue 3 (Composition API) — State management, reactive components, dynamic list rendering, and conditional UI.
* Google Fonts — *Playfair Display* & *Outfit*.
